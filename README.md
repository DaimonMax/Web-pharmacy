# Web-pharmacy
Інтернет-аптека: каталог препаратів з фільтрами, кошик, обране, привʼязка рецептів до рецептурних товарів, оформлення замовлень, "Товар дня" з таймером, окрема адмін-панель для керування замовленнями.

- Next.js 16 (App Router, API routes)
- React 19
- Prisma + SQLite
- JWT-авторизація (кастомна, без сторонніх auth-провайдерів)

- Каталог з фільтрами (категорія, тип, наявність рецепту, ціна, пошук)
- Кошик, обране
- Завантаження та привʼязка рецептів до рецептурних товарів
- Оформлення замовлення, історія замовлень
- Адмін-панель: перегляд усіх замовлень, зміна статусу, редагування адреси,
  видалення позицій
- "Товар дня" — автоматична ротація о 00:00 (Europe/Kyiv)
- Світла/темна тема
